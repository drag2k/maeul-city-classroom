# 마을모아
초등 사회 ‘도시의 의미’ 연구수업용 지도 공동 작업실. 학생은 개인 마을을 모둠에 전송하고 대표는 도시를 편집합니다. 교사는 도시를 전자칠판에 열고 발표용 사본을 저장합니다.

## 실행
Node.js 24에서 `npm run build`, `npm start` 순서로 실행합니다. `npm test`로 독립된 메모리 데이터베이스에서 수업 절차를 검증합니다. 교사용 안내는 앱의 도움말과 `guide.pdf`에 있습니다.

## GitHub와 Vercel
전용 GitHub 저장소를 원격 `github` 또는 `origin`으로 연결하고, Vercel에서 해당 저장소를 가져옵니다. 프로덕션 브랜치는 `main`입니다. 빌드와 출력 폴더는 vercel.json에 지정했습니다. Vercel Functions가 수업 API를 실행하며 서울 리전 비공개 Vercel Blob에 수업을 저장합니다. 기존 수업은 원래 코드와 학생·교사 인증 정보를 유지합니다. 프로덕션과 미리보기는 별도 저장 경로를 사용합니다. 학생에게는 기존 정식 주소의 QR을 안내하세요.
