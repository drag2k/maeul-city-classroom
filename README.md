# 마을모아
초등 사회 ‘도시의 의미’ 연구수업용 지도 공동 작업실. 학생은 개인 마을을 모둠에 전송하고 대표는 도시를 편집합니다. 교사는 도시를 전자칠판에 열고 발표용 사본을 저장합니다.

## 실행
Node.js 24에서 `npm run build`, `npm start` 순서로 실행합니다. `npm test`로 독립된 메모리 데이터베이스에서 수업 절차를 검증합니다. 교사용 안내는 앱의 도움말과 `guide.pdf`에 있습니다.

## GitHub와 Vercel
전용 GitHub 저장소를 원격 `github` 또는 `origin`으로 연결하고, Vercel에서 해당 저장소를 가져옵니다. 프로덕션 브랜치는 `main`입니다. 빌드와 출력 폴더는 vercel.json에 지정했습니다. Vercel은 웹 화면을 제공하며 수업 API는 기존 마을모아 서버로 전달합니다. 두 주소의 수업 자료는 동일한 D1 데이터베이스에 보관됩니다. 기기 연결과 교사 인증은 브라우저 주소별로 관리되므로 한 수업은 같은 주소에서 진행하세요.

변경할 때마다 변경 요약 및 제안 버전을 사용자에게 확인받고 package.json을 수정해 커밋합니다. 승인받은 버전으로 `npm run release -- v0.9.1`처럼 실행하면 수업 검증 후 GitHub에 커밋과 태그를 함께 전송합니다. 연결된 Vercel이 자동으로 배포합니다. 수업 API 자체의 변경은 먼저 기존 서버에 배포합니다.
